### W3 - Explain-like-I'm-5 direction
Director spec (new `direction/eli5.md`, used as the system prompt for Claude when writing episode.json):
- Audience: 5-year-old. Words a child knows; sentences <= 8-10 words; one idea per scene; no jargon (if a real term is needed, name it once after the picture: "grown-ups call this inflation").
- Structure per ViMax/AgentTube merged: Hook (a kid-sized question, 2 s) -> Everyday analogy told as a mini story with a recurring character -> Show it with a picture/animation -> Tiny recap -> "Now you know!" close. 6-9 scenes, 45-60 s.
- Analogy-first for economics: e.g. lemonade stand / candy jar / sharing toys instead of "central bank lever". Real term appears only after the analogy lands.
- Visual rules (from ViMax): each scene has a purpose; first shot widest; wide -> medium -> close; concrete actions; repeat character descriptors verbatim; camera and on-screen motion described separately; no text baked into generated images (Remotion adds text).
- Look: warmer, rounder, brighter kid-friendly palette and font (e.g. Baloo/Fredoka via `@remotion/google-fonts`), big shapes, animated emoji/Lottie stickers, hand-drawn highlights (`rough-notation`), draw-on arrows (`evolvePath`), springy motion.
- Pacing: visual change every 2-3 s; scene length follows narration (`getAudioDurationInSeconds`).
- Facts: `claims[]` with sources; analogy must not distort the mechanism; add a "grown-up check" line in notes, not in the video.
- Accept: ep01 re-written in this style; owner reads script before any paid generation.
